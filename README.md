
# Arise Calistenia

O **Arise** é um projeto web interativo que apresenta o universo da calistenia de forma visual, dinâmica e personalizada. O site combina conteúdo informativo, cadastro de usuários, quizzes e dashboard para mostrar o perfil do praticante e sua evolução ao longo da experiência.

## 🧠 Sobre o Projeto

O projeto foi desenvolvido com a proposta de criar um website com formulário de cadastro, uso de HTML, CSS, JavaScript e integração com o banco de dados.

## Funcionalidades

- ✅ Página inicial com apresentação da calistenia, benefícios e artigos em destaque.
- ✅ Blog contendo artigos relevantes à calistenia.
- ✅ Quiz de categoria para identificar o estilo predominante do usuário na calistenia.
- ✅ Quiz de conhecimento para testar o quanto o usuário sabe sobre a modalidade.
- ✅ Dashboard com indicadores, metas e gráfico radar com pontuação por categoria.
- ✅ Integração com API para envio e consulta de dados do usuário, quizzes e indicadores.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Chart.js para gráficos
- API Web Data Viz - São Paulo Tech School (Node.js) para integração com banco de dados

## Como Rodar o Projeto Localmente

1. Clone o repositório do projeto.
2. Abra a pasta no VS Code.
3. Instale as dependências da API com `npm install`.
4. Configure o banco de dados conforme o script do projeto.
5. Ajuste as variáveis de conexão, se necessário.
6. Inicie a aplicação com `npm start`.
7. Acesse o endereço local exibido no terminal e use o site.
